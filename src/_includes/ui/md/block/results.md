## Technical Details

- Every metric is a list item; the before and after values have hidden "Before:" and "After:" labels, because the strikethrough and the arrow aren't announced. The change has a hidden "Up" or "Down".
- Fewer support tickets and more users are both improvements: the arrow shows the direction, the success color says it's good news, and the text explains it. Use this block for results, not for neutral statistics.
- Add a note with the source and the period of the numbers; it makes them credible.
- Override the content with `resultsBlock`.
