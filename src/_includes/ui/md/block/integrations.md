<p class="lead">An integrations directory with a live search and a grid of connectable apps.</p>

## Technical Details

- The search filters the cards by name and category as you type and announces the number of results in a polite live region; an empty state appears when nothing matches.
- Every card is clickable through the "Connect" link (with a hidden app name for screen readers).
- The logos are colored placeholders built from the first letter and a `--logo-color`; replace them with SVG logos.
- Override the content with `integrationsBlock`.
