<p class="lead">A team block with photo cards and an optional "we’re hiring" card.</p>

## Technical Details

- It combines the [Block Heading](/ui/content-and-layout/block-heading/) and the [Badge](/ui/misc/badge/) components.
- The photos have an empty `alt`, because the name is right below them. Use a real description if the photo adds information.
- Override the content with `teamBlock` (`heading`, `members` with `name`, `role`, `bio`, `photo`, and an optional `hiring` card).
