## Technical Details

- Replace the text placeholders with your SVG logos. Use `fill="currentColor"` so they follow the muted text color, the dark mode and the design style.
- Give every logo image an `alt` with the company name (or use `aria-label` on inline SVGs).
- The list uses the `layout-cluster` mixin with a `'m:l'` (row:column) gap, centered.
