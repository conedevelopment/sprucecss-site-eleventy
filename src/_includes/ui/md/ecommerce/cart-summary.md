<p class="lead">A shopping cart summary with line items, quantity inputs, a discount code field, the totals and the checkout button.</p>

## Technical Details

- Every quantity input has a visually hidden, product-specific label ("Quantity of Everyday Backpack").
- The totals are a description list; the grand total is emphasized with a top border.
- The discount code uses Spruce's `.form-group--stacked` to attach the button to the input.
- The line item grid rearranges on small screens: the quantity moves under the product name.
