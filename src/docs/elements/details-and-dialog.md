<p class="lead">Spruce CSS styles the native disclosure (<code>details</code>) and modal (<code>dialog</code>) elements. They are accessible and keyboard friendly out of the box, so you need little or no JavaScript.</p>

{% notification %}The selectors use <code>:where()</code>, so their specificity is zero: any of your own styles win. Turn them off with the <code>details</code> and <code>dialog</code> generators.{% endnotification %}

## Details

<details>
    <summary>What is Spruce CSS?</summary>
    <p>A Sass-based, minimalistic CSS framework to get the foundation right for any web-based project.</p>
</details>
<details open>
    <summary>Is it open by default?</summary>
    <p>Use the <code>open</code> attribute to render it expanded.</p>
</details>
{% endpreview %}

```html
<details>
    <summary>What is Spruce CSS?</summary>
    <p>A Sass-based, minimalistic CSS framework…</p>
</details>
```

- The marker is replaced with a chevron (a mask of the `select` [form icon](/docs/sass/variables/#form-icon)), which rotates when open and follows the text color.
- Every direct child after the `summary` gets the same inline padding.
- Consecutive `details` elements get a small gap.

### Exclusive Accordion

Give the elements the same `name` attribute, and only one of them can be open at a time (supported in every modern browser):

{% preview %}
<details name="faq-demo">
    <summary>First question</summary>
    <p>Opening another one closes this.</p>
</details>
<details name="faq-demo">
    <summary>Second question</summary>
    <p>No JavaScript involved.</p>
</details>
{% endpreview %}

```html
<details name="faq">…</details>
<details name="faq">…</details>
```

### Variables

```scss
@use 'sprucecss/scss/spruce' with (
  $details: (
    'border-radius': map.get($display, 'border-radius-sm'),
    'border-width': 1px,
    'gap': map.get($spacers, 'xs'),
    'icon-size': 1em,
    'padding': map.get($spacers, 's'),
    'summary-font-weight': 600,
  ),
);
```

## Dialog

{% preview %}
<button class="btn btn--primary" type="button" onclick="document.getElementById('docs-dialog').showModal()">Open dialog</button>
<dialog id="docs-dialog" aria-labelledby="docs-dialog-title">
    <h2 id="docs-dialog-title" class="h4">Delete project?</h2>
    <p>This action can’t be undone.</p>
    <form method="dialog" class="l-cluster">
        <button class="btn btn--danger" value="delete">Delete</button>
        <button class="btn btn--ghost-secondary" value="cancel">Cancel</button>
    </form>
</dialog>
{% endpreview %}

```html
<button class="btn btn--primary" type="button" data-open="confirm-dialog">Open dialog</button>

<dialog id="confirm-dialog" aria-labelledby="confirm-dialog-title">
    <h2 id="confirm-dialog-title">Delete project?</h2>
    <p>This action can’t be undone.</p>
    <form method="dialog">
        <button class="btn btn--danger" value="delete">Delete</button>
        <button class="btn btn--ghost-secondary" value="cancel">Cancel</button>
    </form>
</dialog>
```

```js
document.querySelector('[data-open="confirm-dialog"]').addEventListener('click', () => {
  document.getElementById('confirm-dialog').showModal();
});
```

- Open it with `showModal()`: the browser traps the focus, closes it with <kbd>Esc</kbd>, makes the page inert and returns the focus to the opener.
- A `form method="dialog"` closes the dialog on submit, and `dialog.returnValue` tells you which button was pressed.
- The `::backdrop` uses the `overlay` color and the optional `backdrop-filter`.
- Label the dialog with its heading (`aria-labelledby`).

### Variables

```scss
@use 'sprucecss/scss/spruce' with (
  $dialog: (
    'backdrop-filter': none, // like blur(4px)
    'border-radius': map.get($display, 'border-radius-lg'),
    'border-width': 1px,
    'inline-size': 40rem,
    'padding': map.get($spacers, 'm'),
  ),
);
```

Need a side panel instead? See the [Drawer component](/ui/content-and-layout/drawer/), built on the same element.

## Generators

Both are generated by `generate-styles`. To use them with a custom selector (for example, only with a class), turn off the generator and include the mixin yourself:

```scss
@use 'sprucecss/scss/spruce' as *;

@include generate-details('.accordion');
@include generate-dialog('.modal');
```
